# 森林火险瞭望与卫星热点核查系统

融合**瞭望塔台人工观测**与**卫星红外热点**两类火险情报，经时空去重融合为
火情事件并自动定级，随后按责任区、距离与负载均衡向一线护林员派发**核查清单**，
实现"多源发现 → 自动去重 → 限期核查 → 回传闭环"。

## 数据流

```
瞭望塔台观测（方位角+估算距离）─┐
                               ├─→ 归一化 Detection → 时空聚类去重 → 加权质心定位
卫星红外热点（FIRMS 风格）   ──┘        → 多源互证风险定级 → 派发核查清单 → 护林员
```

## 快速开始

```bash
python3 main.py                          # 运行内置演示场景（8 条报告 → 3 个事件）
python3 main.py --spatial-km 3 --temporal-hours 6   # 调整去重阈值
python3 main.py --json result.json       # 导出派发结果
python3 -m unittest discover -s tests    # 运行 17 个单元测试
```

无第三方依赖，Python ≥ 3.10 即可运行。

## 目录结构

```
forest_fire/
├── geo.py        # 球面大地计算：haversine 距离、方位角、塔台定位推算
├── models.py     # 领域模型：观测/热点/探测/火情事件/护林员/核查任务
├── fusion.py     # 归一化、时空去重聚类、加权质心、风险定级
└── dispatch.py   # 派发策略与核查清单生成
main.py           # 端到端演示流水线（含虚构"云岭林区"场景数据）
tests/            # 单元测试
```

## 核心逻辑

### 1. 归一化（fusion.py）
- **塔台观测**：由塔位 + 方位角 + 估算距离推算烟点坐标（`geo.destination_point`）。
  肉眼见烟可信度高（0.7），但距离系人工估算，定位权重低（0.5）；缺距离时仅作人工研判。
- **卫星热点**：兼容 FIRMS 字段，置信度支持 `0-100` 数值与 `low/nominal/high` 档位，
  定位权重随置信度 0.5~1.0 浮动。

### 2. 时空去重（`fuse_detections`）
按时间排序后增量聚类：与既有事件质心距离 ≤ **2km** 且距该事件末次探测 ≤ **12h**
的探测并入该事件（阈值可调）。同一火情的多次卫星过顶、多塔重复报告由此合并，
事件位置取各探测的**加权质心**。

### 3. 风险定级（`assess_risk`）
| 评分项 | 分值 |
|---|---|
| 塔台+卫星互证 / 仅塔台 | +2 / +1 |
| 最高置信度 ≥0.8 / ≥0.5 | +2 / +1 |
| 最大 FRP ≥50MW / ≥20MW | +2 / +1 |

≥5 分**高风险**、≥3 分**中风险**、其余**低风险**。单一卫星热点最高 4 分——
未经地面核查不定为高，这正是派发核查的意义。

### 4. 派发（`dispatch_events`）
高风险优先、同级按首见时间排序；选人规则：**责任区内 → 负载最轻 → 距离最近**，
无人覆盖时就近**跨区支援**并标记。核查时限：高 1h / 中 2h / 低 4h；
每人单班最多 3 个并发任务，满负荷时向上级告警。

## 生产化扩展方向

- **数据接入**：NASA FIRMS API / 风云、高分卫星下行业流；塔台观测 App 上报；
  多塔交汇定位（两条方位线交会，替代单塔估距）。
- **存储与检索**：PostGIS 空间索引替代内存聚类；事件状态机持久化。
- **推送通道**：北斗短报文 / 微信小程序 / 对讲调度系统下发清单，回传自动销号。
- **去重增强**：DBSCAN 聚类、按火险天气等级动态调整时空阈值、
  已知热源（厂矿、农事用火区）白名单过滤。
