# 森林火险瞭望与卫星热点核查系统

融合**瞭望塔人工观测**与**卫星热点**（VIIRS / MODIS / FY-4A 等），自动去重融合为火情事件，
按优先级向一线护林员就近派发**核查清单**，并支持核查结论回传闭环。

纯 Python 3 标准库实现，零第三方依赖。

## 数据流

```
塔台观测(方位角+估距) ──→ 单站定位 ─┐
                                  ├→ 时空聚类去重（并查集）→ 事件内多塔三角定位升级
卫星热点(VIIRS/MODIS…) ──────────┘        │
                                          ▼
                              融合火情事件（位置/置信度/FRP）
                                          ▼
                        优先级分级 → 就近派单（容量约束）→ 核查清单
                                          ▼
                        护林员回传结论 → 事件状态闭环（确认火情/误报/需增援）
```

## 快速开始

```bash
cd forest-fire-ffs

# 1. 运行融合派发流水线（读取 data/，输出到 out/）
python3 main.py run --data data --out out

# 2. 查看事件与任务状态
python3 main.py status

# 3. 护林员回传核查结论
python3 main.py feedback --task T-0001 --result confirmed --note "现场明火2处"
#    --result 可选：confirmed(确认火情) / false_alarm(误报) / need_backup(需增援)

# 运行测试（19 项）
python3 -m unittest discover -s tests -v
```

输出物：

| 路径 | 内容 |
|---|---|
| `out/checklists/T-XXXX.txt` | 每项任务一份可打印/短信下发的核查清单 |
| `out/summary.json` | 事件与任务汇总（供指挥端/地图端消费） |
| `out/ffs.db` | SQLite 库（events / tasks 两表，含反馈记录） |

## 核心算法

- **塔台单站定位**：方位角 + 目测距离 → 球面目的地推算；不确定度 `max(400m, 0.22×距离)`。
- **多塔三角定位**：同一事件内 ≥2 座塔、上报间隔 ≤45 分钟时，方位线最小二乘交会；
  残差 >1.5 km 或交会点位于塔后时自动放弃，回退单站定位。
- **时空去重**：两候选点距离 ≤ 各自不确定度之和 且 时间差 ≤3 小时（卫星重访量级），
  并查集归并。不确定度按传感器像元尺度取值（VIIRS 375 m / MODIS 1 km / 静止卫星 2 km）。
- **位置融合**：逆方差加权质心；**置信度**：独立源概率合成 `1-∏(1-cᵢ)`，
  塔台与卫星互相印证 +0.10，封顶 0.99。
- **派发**：按（优先级, 置信度, 发现时间）排序，分配给最近的、在办未达上限的护林员；
  时限 P1 2h / P2 4h / P3 8h，预计到达时间按山区 25 km/h 估算。

## 目录结构

```
forest-fire-ffs/
├── main.py              # 命令行入口（run / status / feedback）
├── ffs/
│   ├── geo.py           # 球面距离、方位定位、最小二乘三角定位
│   ├── models.py        # 数据模型
│   ├── fusion.py        # 融合去重引擎（核心）
│   ├── dispatch.py      # 优先级、派单、核查清单生成
│   ├── store.py         # SQLite 持久化与反馈闭环
│   └── pipeline.py      # 端到端流水线
├── data/                # 样例数据（滇中某林区：3 塔 / 5 护林员 / 7 热点 / 3 观测）
└── tests/               # 19 项单元与端到端测试
```

## 已知假设与扩展方向

- 塔台观测员目测距离存在误差，系统以 22% 误差系数建模；接入激光测距仪可显著提高单站定位精度。
- 多火并行且方位线交叉时可能产生"鬼点"，当前以目测距离锚定 + 交会残差校验抑制；
  可进一步引入地形通视分析（DEM）排除不可见区域。
- 派发目前为直线距离就近，可扩展为路网/步道可达性 + 护林员技能与装备匹配。
- 数据接入目前为 JSON 文件，可平滑替换为卫星热点 API（如 FIRMS）、瞭望塔上报 App、
  短信/北斗短报文下发通道。
